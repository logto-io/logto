label icon-only buttons in the sign-in experience and Account Center for screen readers, and let Space activate the country code selector

Screen readers now announce the clear buttons on identifier and password fields as "Clear", and the close buttons on dialogs and the sign-in experience navigation bar as "Close". The arrow button of select fields is announced by the field label along with whether its options are expanded. The country code selector and its options now respond to Space as well as Enter.
